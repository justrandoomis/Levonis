## Bloub SVG morphing reference

The Levonis home character adapts the SVG path-morphing technique and
event-state idea demonstrated by [jeremy-prt/bloub](https://github.com/jeremy-prt/bloub).
The integrated character artwork, palette and React implementation are Levonis-specific;
the original Vue application is not bundled.
