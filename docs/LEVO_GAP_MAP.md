# Levo master spec: architecture and gap map (§02)

This is the short map that spec §02 asks for: what works, what is partial, what is missing, the integration points, the duplication risks and the real code locations. It also holds the conflicts list, the items blocked outside the code, and the reference studies to run when each track starts.

- **Code base:** Phase 0 audited `b8233ee3`. Refreshed on 2026-10-20 against `aa713842` (live): what landed since Phase 0 is marked **Resolved** with its commit, and the owner's answers to Q1-Q8 (DECISIONS row 262) are marked **Answered**. See [Since Phase 0](#since-phase-0).
- **Companions:** `docs/LEVO_ACCEPTANCE_MATRIX.md` has one row per requirement with its evidence and run links. `docs/LEVO_PLAN_PHASE1_2.md` has the pushes and their status. `docs/LEVO_REFERENCE_MATRIX.md` holds the reference study.
- **Counts (611 rows) at `aa713842`, after P1-14:** 163 done, 293 partial, 133 missing, 2 conflict, 20 blocked-external. At Phase 0 they were 135, 316, 136, 4 and 20 (after the AI-layer re-status below).

> **Owner decision recorded while this audit ran (2026-10-19, DECISIONS row 262, «AI layer»).**
> - Use Cloudflare Workers AI (binding `AI`) and the Claude API (`ANTHROPIC_API_KEY`).
> - Both sit behind a provider-agnostic adapter with per-capability routing, a hard daily spend ceiling and a basic mode.
> - A model never states a price, stock, compatibility verdict or HMS meaning, and never writes Sorani.
>
> Smart Diagnose is still built without any paid AI key (the owner's answer of the same day). Effects:
> - three rows move from blocked-external to missing (`24.provider-boundary`, `29.44`, `29.45`);
> - conflicts 46 and 63 are resolved;
> - image-to-3D, server render and the AI generation queue are still blocked on a GPU host.
