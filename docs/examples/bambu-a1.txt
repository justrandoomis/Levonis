#  Bambu Lab A1 — نسختان، وطريقتا شراء لكل نسخة، بسعرٍ واحد وزيادات
#  One product. Two models. Two ways to buy each. ONE base price, then increases.
# ============================================================
#
#          |  طلب مسبق جوي (pre-order, air) |  بيع مباشر (direct sale)
#  --------+--------------------------------+--------------------------
#   A1     |  899,000 + 25,000              |  899,000 + 51,000
#   A1 Combo| 1,099,000 + 25,000            |  1,099,000 + 51,000
#
#  قاعدة المالك: «سعر المنتج يوضع الأرخص ليكون الخيارات والألوان والتوفر
#  عبارة عن زيادة». فهذا الملف يقول ثلاثة أشياء فقط:
#
#  1. `price_iqd=899000` هو الأرخص. الـ Combo زيادة فوقه: `+200000`.
#  2. التوفر حسب المنتج، لا حسب الخيار. `selling_type=mixed` = يُباع بالطريقتين،
#     و`availability_type` للخيارَين فارغ. لا يوجد خيار «A1 — طلب مسبق» وآخر
#     «A1 — بيع مباشر»: النسخة واحدة، والطريقة يختارها الزبون في السلة.
#  3. فرق الطريقة زيادة على المنتج: البيع المباشر `direct_surcharge_iqd=51000`
#     (لا تُعفى بالعضوية)، والطلب المسبق الجوي `transports.1.commission_iqd=25000`
#     (تُعفى لأعضاء PRO الفعالين). البري والبحري معطّلان هنا؛ لتفعيل البري اكتب
#     `transports.3.active=true` وزيادته في `transports.3.commission_iqd`
#     (أو بكلمة الواجهة `transports.3.surcharge_iqd`).
#
#  رقم بلا إشارة في regular_price_iqd ما زال مقبولًا كسعر ثابت، ويُعاد
#  التعبير عنه كزيادة فوق الأساسي عند الاستيراد — ما يدفعه الزبون لا يتغيّر.
#
# القالب الفارغ الكامل: زر «تنزيل قالب TXT» في نافذة الاستيراد/التصدير.
# ============================================================
