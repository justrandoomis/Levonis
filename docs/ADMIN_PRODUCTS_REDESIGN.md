# إعادة تصميم صفحة إدارة المنتجات (لوحة الأدمن)

تقرير التسليم لجولة إعادة التصميم الممتازة لصفحة `/admin → المنتجات` (القرارات
81 و82 في `DECISIONS.md`). كل الوظائف بقيت كما هي: نفس نقاط `/api/admin/products-v2`،
نفس المحرر، نفس الاستيراد/التصدير، ونفس المرتكزات التي تقيسها سويتات القبول.

## 1) ملخص التغييرات

- **لوحة ألوان داكنة احترافية** مُقيَّدة بالصفحة (`.ap`): أرضية الهيكل `#18181b` وأربع
  طبقات سطوح فوقها بفارق ~3 L* وخطوط شعرية 1px — عمق بالطبقات لا بالتوهج. لون
  تمييز بنفسجي واحد يؤدي أربعة أدوار (زر أساسي، تركيز، تحديد، رقاقة نشطة)، وألوان
  دلالية مُخفَّفة الإشباع على أرضيات 14%، وكل نص/شارة يجتاز AA (الجدول أدناه).
- **أزرار أصغر ومصقولة**: نصية 36px وأيقونية 32px، بحالات hover / active / focus-visible
  / disabled لكل نوع، والحالة المفتوحة/المضغوطة تأتي من `aria-expanded` /
  `aria-pressed` / `aria-current` لا من تجاوزات `!`. القوائم المنسدلة بقيت 40px لأن
  سويت القبول تقيس كل `<select>` في الصفحة.
- **شريط علوي مدمج مع ⌘K حقيقي**: مسار التنقل + لوحة انتقال سريع (combobox) تعرض
  أقرب 8 نتائج وتفتح المحرر بـEnter، تعمل بلوحة مفاتيح عربية/كردية (المفتاح
  الفيزيائي)، وتُتجاهل عندما يكون حوار مفتوحًا.
- **بطاقات إحصاء** خمس بأرقام حقيقية من `/stats` ورسوم شرارة (sparklines) بسلاسل
  حقيقية؛ عمودان على الهاتف (الخامسة تمتد) وخمسة أعمدة من lg.
- **صف بحث/فلاتر** (بحث، قسم، حالة، مخزون، شريحة سعر، فترة، تصفية متقدمة: مميز /
  علامة / نطاق سعر يدوي) — كلها تُنفَّذ على الخادم، مع debounce للبحث والسعر.
- **مبدّل عرض** ثلاثي (شبكة / جدول / مضغوط) بذاكرة محلية، وشريط أدوات (النطاق، حجم
  الصفحة، الترتيب).
- **صفوف جدول متقدمة**: صورة مصغّرة، الاسم + العلامة/الاسم الإنجليزي + SKU، السعر
  (+PRO)، المخزون بثلاث حالات (متوفر / منخفض بعتبة المنتج / نفد)، شارة حالة
  نقطة+نص، المبيعات، آخر تحديث، وإجراءات (حذف، تعديل، ⋯ قائمة: إخفاء/نشر، فتح،
  نسخ الرابط).
- **قوائم بعقد لوحة مفاتيح كامل**: التركيز على أول عنصر، ↑↓ / Home / End، Escape يغلق
  ويعيد التركيز، Tab يغلق؛ والقوائم لا تُقصّ أبدًا خارج العمود.
- **استجابة و RTL**: لا تمرير جانبي عند 390 / 768 / 1024 / 1440 بالاتجاهين، سهم
  القوائم مرسوم بـCSS منطقي الاتجاه، والأرقام معزولة `dir="ltr"` داخل نص عربي.
- **تحسينات وصول**: تسميات مُترجمة لكل أداة، `aria-activedescendant` في الانتقال
  السريع، أهداف لمس ≥ 32px للأيقونات و36px للنصية، وتباين AA في كل مكان.
